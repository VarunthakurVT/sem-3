## Python Comparison Operators, Identity, and Memory Concepts

`==` checks whether two values are equal and is used as a comparison operator

`is` checks whether two objects refer to the same object, particularly the same memory location

Equality comparison and object identity should not be treated as interchangeable concepts

Python was described in class as handling object references and memory automatically, so students do not normally use explicit pointer syntax as in C++

Variable reassignment was connected to object allocation and memory release

Constructors and destructors from C++ were used as a reference point for understanding object creation, allocation, and freeing memory

The instructor stated that Python does not include a triple-equals operator because it does not provide a built-in operator with that behavior

Python does not have a standard `do while` loop; indentation and implementation concerns were mentioned as reasons for using other control-flow structures instead

## Python Output, Strings, and Common Functions

Python output formatting methods include f-strings, formatted strings, and percent-style formatting

F-strings were identified as formatted strings used to embed values in output

`replace()` substitutes one part of a string with another

`join()` combines multiple strings into a single string

`append()` adds one item to a collection

`extend()` adds multiple items to a collection

Escape characters and escape sequences were included among the Python basics students should know
