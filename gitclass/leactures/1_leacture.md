## Git’s Role as a Distributed Version-Control System

Git tracks changes made to software files so developers can review, restore, and manage project history

Centralized systems store changes mainly on a single server, while distributed systems maintain project data locally as well

GitHub provides a shared remote server where local Git repositories can be updated and accessed by authorized team members

Previous versions can be restored after accidental deletion, software crashes, faulty changes, or other problems

Git protects project history when another person changes or damages code, provided the work has been committed and stored properly

Long-running projects become safer because months of development work can be recovered instead of being permanently lost

## Installation and Basic Command Preparation

Laptop requirement: students should bring their laptops to the next class for installation and practical work

Windows users should download Git from the official website using the Windows-specific link

Linux and Mac systems may already include Git, but installation should be verified

Version check: run `git version` in a terminal to confirm whether Git is installed and view its installed version

Git Bash will be used for Git-related commands because it provides a Bash-style environment based on Linux conventions

Basic shell commands such as `cd` for changing directories and `mkdir` for creating directories may be practiced

Some commands may behave differently in a normal terminal, so Git commands should be run through Git Bash when required

The instructor offered to provide class time for installation or clarification if students need support

## Industry Relevance, Projects, and Class Administration

Git is an essential industry skill rather than a time-pass subject, especially for students seeking IT or software-development roles

Team development requires version control because a complete software product is rarely built by only one individual

Practical project workflow: students can upload an existing project to Git and use it to demonstrate project history and controlled changes

Students suggested placing one of their projects on Git, with clarification that the relevant project was not simply the seminar project

Git terminology requires attention because terms such as file, project, branch, and repository may be used differently in technical discussions
