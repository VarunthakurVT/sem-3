## Python Type Casting and Basic Errors

**Type casting**: converting a value from one data type to another, such as converting an integer into another numeric type

Strings containing letters, such as `"ABC"`, cannot be directly converted into integers because the characters do not represent a numeric value

Numeric values can be converted when the target data type can interpret them correctly

Equality comparisons use matching values and types; strings such as `"hello"` and `"Hello"` are different because their letter cases do not match

A misspelled function name, such as writing an incorrect version of `print`, produces a `NameError`

Python is an interpreted language, so code is processed line by line and errors are identified during execution

## Variables, Expressions, and Operator Precedence

Variables store values so they can be reused in calculations and printed later

Simple expressions can be written directly when faster computation and minimal memory usage are preferred

Variables become more useful when expressions or problem statements become complicated

Arithmetic examples included addition, subtraction, and division

BODMAS/operator precedence determines the order in which arithmetic operations are evaluated

Students were asked to calculate expressions such as adding `30` and `70`, and subtracting `5` from `25` before dividing the result by `10`

Practical-lab time examples included `43` minutes, `42` minutes, and `37` minutes for different practicals

## Strings, Indexing, and Slicing

Characters and groups of characters are represented as strings in Python

Spaces count as string characters and can appear as output without causing an error

Positive indexing identifies characters from the left, while negative indexing identifies positions from the right
