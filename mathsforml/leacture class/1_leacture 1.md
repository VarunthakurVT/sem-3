# Statistics Lecture: Data Types, Classification, Variables, Frequency Distributions, and Tally Marks


## Overview: Statistics lecture on data classification and frequency distributions

Education session explaining data, its sources and classifications, variables, frequency, range, and frequency distributions


Data was categorized as qualitative or quantitative, with primary and secondary sources

Discrete and continuous frequency distributions were distinguished using observation count and data range

Tally marks were demonstrated for checking frequencies and validating a 20-family survey

## Data Definition, Types, and Sources

**Data**: A statement or collection of facts from any department of inquiry, such as students’ marks or heights

**Qualitative data**: Information classified according to qualities or characteristics

Examples included rural versus urban background and gender categories such as male and female

**Quantitative data**: Information represented through numerical values

**Primary source**: Original data collected directly by an investigator or individual

**Secondary source**: Data already collected by another agency or source, including information obtained from newspapers or other existing records

---

## Four Methods of Classifying Data

**Geographical classification**: Data organized by area, location, district, or state

Example: Classifying 50 students according to their districts in Himachal Pradesh or their different states

**Chronological classification**: Data organized according to time periods

Time periods may include decades, centuries, years, months, days, hours, minutes, or seconds

Example: Number of Computer Science students admitted from 2020 to 2023

**Qualitative classification**: Data grouped by traits such as rural or urban background and male or female gender

**Quantitative classification**: Data grouped according to numerical values, often to create a frequency distribution

---

## Variables, Discrete Values, and Continuous Values

**Variable**: A characteristic that takes different values from one individual or observation to another

Examples included CGPA/OGPA, age, and the number of children in a family

**Discrete variable**: A countable variable with finite or integer values

Examples: number of children, number of students, and number of mobile phones

Values may be 1, 2, or 3, but not 2.5 when counting objects

**Continuous variable**: A variable capable of taking all possible values within a given limit

Examples: OGPA values such as 5.2, 5.1, and 5.8; temperature values such as 20.5 and 30.8; weight, height, and marks

**Range**: The difference between the maximum and minimum values in a data set

**Frequency**: The number of times a particular value occurs

---

## Choosing Discrete or Continuous Frequency Distribution

A data set with many observations but a small range is generally converted into a discrete frequency distribution

A data set with many observations and a large range is generally grouped into a continuous frequency distribution

**20-family children survey**:

Recorded numbers of children included values from 0 to 5

Minimum value was 0 and maximum value was 5, so the range was small

Because the 20 observations repeated several values, the data was organized as a discrete frequency distribution

**Discrete distribution format**:

Variable (X) represented the number of children in a family

Possible values were 0, 1, 2, 3, 4, and 5

Tally marks were used to count each occurrence

The frequency totals were checked against the 20 observations; a total of 19 would indicate a missing observation, while 21 would indicate double-counting

The example counted 1 family with 0 children, 4 families with 1 child, and 7 families with 2 children

The lecturer also considered counts such as families with fewer than 2 children and families with more than 5 children

---

## Continuous Classes and Boundary Rules

Marks provide an example of continuous grouping because a class may contain 50 students whose marks range from 0 to 100

Suggested class intervals were:

0–10

10–20

20–30

30–40

Continuing through 90–100

**Class limits**:

The first value is the lower limit

The second value is the upper limit

Observations are included according to the lower-limit rule, except for the final class

A value of 43 belongs in the 40–50 class

A value of 50 belongs in the 50–60 class

A value of 100 is included in the final 90–100 class

Without the special treatment of the last class, an additional 100–110 interval would be needed
